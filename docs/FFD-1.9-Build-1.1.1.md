# FFD 1.9 Build 1.1.1 — Full-Width Publication Image Refinement

Refines the accepted Family Book publication layout.

- All publication image orientations now use the same natural-size rule: preserve aspect ratio, expand only until the available content width is reached, and never force a smaller original beyond its intrinsic size.
- Portrait, landscape, square, and hero images no longer use separate publication height caps.
- Publishing activity movement and stage feedback remain, while the redundant final explanatory line is removed.
- Applies to the shared HTML/PDF Family Book publication stylesheet.
