# FFD 2.0 RC1.0.3 — Birth Document Section Pagination

Baseline: FFD 2.0 RC1.0.3 — Atomic Media & Descendant Typography Repair  
Genealogy engine: FFD 1.9 RC1

This is a deliberately narrow final RC1.0.3 publication-layout adjustment.

- When Birth Documents exists for a person, its section begins on a fresh printed page.
- This prevents the Birth Documents heading being orphaned at the bottom of the preceding Biography page while the certificate starts on the next page.
- The rule applies only to Birth Documents; Death & Burial, Military and Other Documents retain their existing flow.
- Existing PDF document rendering, portrait/wedding atomicity, landscape-pair pagination, descendant typography, source citations, PDF-only cleanup and backend behaviour are unchanged.
