# FFD 2.0 RC1.0.7 — Application Shell & Research Overview QA Pass 1

## Scope

This pass standardises the application utility header across Presentation and Research modes and removes obsolete in-page navigation from the Research person overview.

## Acceptance rules

- Presentation and Research use the same Reunion Companion brand size, header geometry, Family History selector and mode control.
- Changing mode changes selected state and available contextual navigation, not utility-header sizing.
- Research person Overview contains research/person content only; the left sidebar owns navigation.
- Presentation Overview, Life Story, Family, Search, identity discovery, Ask about, publishing and reports are unchanged.
