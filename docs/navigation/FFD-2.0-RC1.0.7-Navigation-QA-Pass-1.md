# FFD 2.0 RC1.0.7 — Person Presentation & Application Navigation — Navigation QA Pass 1

## Scope

This pass simplifies Reunion Companion navigation without changing genealogy, search, relationship, GEDCOM, or publishing behaviour.

## Navigation states

### Before a person is selected

**COMPANION**
- Home
- Search
- Ask

### Presentation mode with a selected person

**COMPANION**
- Home
- Search
- Ask

**[SELECTED PERSON]**
- Overview
- Family Chart
- Timeline
- Biography
- Family
- Media
- Ask about

**OUTPUT**
- Publish
- Reports

### Research mode with a selected person

**COMPANION**
- Home
- Search
- Ask

**RESEARCH — [SELECTED PERSON]**
- Overview
- Family Chart
- Timeline
- Biography
- Family
- Media
- Sources
- Confidence
- Research
- Data Quality
- Ask about

**OUTPUT**
- Publish
- Reports

## Top utility area

The old Presentation button is replaced by a persistent **Presentation | Research** mode selector. The active Family History selector sits beside it. Global Home/Search/Reports navigation and visible build identity are removed from the top bar.

## Compatibility

The existing horizontal person navigation helpers remain available for compatibility, but person and question pages no longer render that duplicate navigation. RC1.0.6 Search & Identity Discovery behaviour is unchanged.
