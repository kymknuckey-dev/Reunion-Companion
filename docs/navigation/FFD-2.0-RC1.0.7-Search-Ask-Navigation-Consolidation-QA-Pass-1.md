# FFD 2.0 RC1.0.7 — Search & Ask Navigation Consolidation QA Pass 1

## Purpose
Consolidate no-context discovery and questioning behind Search while retaining contextual Ask about for a selected person.

## Rules
- COMPANION contains Home and Search only.
- The top-level Ask navigation entry is removed in Presentation and Research modes.
- Search remains the no-context entry for person discovery and natural-language questions.
- Ask about remains available once a person context exists.
- The underlying questions route is retained for contextual conversation.
- Search identity discovery and answer behaviour are not redesigned in this pass.
- Accepted Visual Presentation QA Pass 4 presentation is unchanged.
