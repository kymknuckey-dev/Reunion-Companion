# FFD 2.0 RC1.0.7 — Visual Presentation QA Pass 2

## Scope

Visual refinement of the accepted person Overview presentation.

- Explicit photo and no-photo hero states.
- Photo hero uses a stable 4:5 portrait frame and isolated text column.
- No-photo hero expands identity content to the full available width and contracts vertically.
- Life Story retains semantic event/fact icons and restores a separate chronology spine with navy event dots.
- Existing Family, navigation, search, genealogy, research and publishing behaviour remains unchanged.

## Visual contract

The sidebar owns navigation; Overview owns presentation. Real person photographs remain preferred in Family rows, with Companion male/female/neutral placeholders as fallback.
