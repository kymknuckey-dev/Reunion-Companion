# FFD 2.0 RC1.0.7 — Person Presentation & Application Navigation

## Purpose
Make the selected person the visual focus of Reunion Companion while establishing a stable application navigation shell.

## Application shell
- Adds a persistent left application sidebar for Home, Search, Ask, People, Media, Places, Sources, Research, Data Quality and Reports.
- Presentation mode keeps the user-facing exploration/output destinations while suppressing research-only sidebar entries.
- Existing top-level family-file selection and Presentation Mode controls remain intact.

## Selected-person presentation
- Adds a persistent selected-person identity strip with portrait (when available), full name, lifespan and concise family context.
- The existing person tabs remain the navigation for views of the selected person.
- Research mode retains the GEDCOM cross-reference in the person identity strip.

## Overview / Life Story
- Removes the duplicated action-card navigation and Explore Further block.
- Uses a larger editorial portrait and stronger person-first hierarchy.
- Replaces database-oriented Life at a Glance counters with human context where available: birth year, spouse, children and occupation.
- Presents Key Life Events as a restrained chronological sequence.
- Keeps Immediate Family / Close Family and direct person links.
- Adds image previews to Media & Documents when local media is available.

## Scope protection
No intentional changes to RC1.0.6 Search & Identity Discovery, relationship resolution, GEDCOM handling, genealogy assembly or publishing internals.
