# FFD 2.0 RC1.0.7 — Visual Presentation QA Pass 4

## Scope
Refine only the accepted Person Overview Life Story timeline. Hero, Family, navigation, Search & Identity Discovery, research and publishing remain frozen.

## Life Story contract
- Use one continuous Life Story timeline; there is no separate Recorded Facts subsection.
- Display only information actually recorded for the person.
- Dated entries display their year; undated entries retain a blank year position and no date is invented.
- Ordinary dated events remain chronological. Undated life facts are presented in a stable, useful life-story order before terminal events.
- Death, when recorded, is terminal to the life sequence except for final disposition.
- Burial, cremation or equivalent final disposition, when recorded, is always the final timeline entry. If absent, no placeholder row is shown.
- The navy chronology dot/spine and cream semantic event icon remain separate visual elements.
