# FFD 2.0 RC1.0.13.1 — Persistent Global Navigation, Person Header Parity & Home Explore Removal

## Persistent global navigation

### Presentation mode
Before and after a person is selected:

- COMPANION
  - Home
  - Search
- OUTPUT
  - Reports

When a person is selected, the person-specific navigation is added and Publish joins Output.

### Research mode
Before and after a person is selected:

- COMPANION
  - Home
  - Search
- RESEARCH
  - Priorities
  - Improve
  - Manage
- OUTPUT
  - Reports

When a person is selected, the person-specific navigation is added and Publish joins Output.

## Home
The duplicated Explore/Research launch-card section is no longer rendered on either Home mode because those destinations now live persistently in the sidebar.

Family to Explore, A Living Family History, search, and Family History at a Glance remain.

## Person header parity
The existing person-context header is now also shown on:
- Family Chart
- Ask about

This makes the person workspace consistent across all person-context destinations.

The person header identifies the workspace person. The compact conversation-focus bar continues to identify conversational focus independently.

## Regression boundary
Do not change context-search semantics, relationship resolution, focus transitions, genealogy, publishing, History Book scope, or report generation.
