# FFD 2.0 RC1.0.12.4.3 — Publish Families Duplication Removal

## Scope
Remove the redundant **Families** section from Person > Publish.

The primary **Descendant Report…** action is now the single Publish entry point:
- one spouse family: selected automatically;
- multiple spouse families: choose the starting family in the Descendant Report workflow;
- then choose 1–6 generations and HTML/PDF.

No family records, Family workspace, Descendant Report generation, History Book, genealogy or publishing data are removed.

## Deferred
Research Profile, Biography and Person Report remain functional but their mixed research/presentation styling is deferred to a later Publishing Presentation Harmonisation pass.
