# FFD 2.0 RC1.0.14.8.9.9.4.1.3.12.10.5 — Improve Media Filename Standards

- Adds **Non-standard filename** to the existing Improve > Data Quality Centre Media status row.
- Uses `Surname, First names [optional descriptive text].extension` as the baseline while leaving descriptive text unrestricted.
- Clicking the status shows the non-conforming filenames in the existing Media browser.
- Removes the redundant lower **Missing media**, **Legacy PICT**, and **Untitled sources** cards.
- Keeps Place variants and Duplicate source titles unchanged.
- Filename review is read-only; Companion does not rename, move, or delete Media files.
